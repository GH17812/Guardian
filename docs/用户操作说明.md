# Guardian 用户操作说明

## 1. 安装与启动

1. 运行 `installer\install.ps1`（管理员）。脚本会：发布/复制程序到 `C:\Program Files\Guardian`、注册并启动 `GuardianService` 服务、创建桌面与开始菜单快捷方式。
2. 双击 **Guardian** 快捷方式打开主界面。若服务未运行，界面顶部会显示横幅，可点击"安装/启动服务"（需要管理员）。
3. 关闭窗口时程序最小化到系统托盘，双击托盘图标可重新打开；托盘菜单提供快捷操作与"退出"。

## 2. 主界面

- **总开关（大圆钮）**：开启保护 / 解除保护。这是最常用的控制，始终位于主界面中央。
- **模式选择**：
  - 隐私保护：关闭本地显示器输出，保持系统运行，不隔离输入。
  - 输入隔离：在隐私保护基础上隔离本地物理键盘/鼠标（实验性）。
  - 增强隔离：Phase 2 能力，当前版本不可用。
- **状态磁贴**：显示隐私、输入隔离、电源保护、活动会话、电源（交流/电池）、远程会话、显示器数量。
- **工作会话**：列表 + 新建/结束按钮。
- **紧急恢复**：红色按钮，随时可用。
- 底部状态栏：服务连接状态、服务版本、最近一次保护操作。

## 3. 首次开启保护（显示隐私验证）

第一次开启保护（隐私或隔离模式）时：

1. 弹出提示：确认后**本机显示器将被关闭**，请在远程端（RDP/Sunshine/Parsec 等）确认画面是否正常。
2. 开启成功后再次询问"远程画面是否正常"：
   - 正常 → 记录本机验证通过，以后不再强制询问；
   - 异常 → 立即自动恢复，并记录验证失败（可在设置里重新验证）。

> 验证结果只针对当前机器与远程方案组合。更换串流软件、显卡驱动后建议重新验证。

## 4. 工作会话

新建会话需填写：

- 名称（必填）；
- 工作负载类型：远程桌面 / AI Agent / RPA 自动化 / 编译 / 渲染 / 本地推理 / 其他；
- 所需保护模式；
- 最长时长（分钟，可选，超时自动结束）；
- 是否允许自动结束。

规则：

- 多个会话同时存在时，按最高模式生效；只有全部会话结束（或用户手动解除）后保护才释放。
- 手动"解除保护"只解除手动开关；若有活动会话，保护继续维持（界面会提示）。
- 紧急恢复会结束全部会话。

## 5. 紧急恢复

两种方式，均不依赖网络、不依赖被隔离的输入以外的通道：

1. **界面按钮**：主界面左下角"紧急恢复"（需二次确认）。
2. **快捷键**：`Ctrl + Alt + Shift + F12`（可在设置中换主键 F8/F9/F10/F11/F12/Pause）。输入隔离期间由服务端钩子直接识别；未隔离时直接点按钮或重启应用即可（未被隔离，无风险）。

恢复动作：解除输入隔离 → 恢复显示器 → 释放电源请求 → 结束全部会话 → 记录恢复日志。

## 6. 设置

- **应用**：界面语言（中文/English）、主题（浅色/深色/跟随系统）。
- **保护服务**：
  - 紧急恢复主键；
  - UI 丢失动作：默认"自动恢复"（客户端崩溃/被杀时自动解除保护）；无人值守场景可改"保持保护"；
  - 服务重启策略：默认"恢复系统"（fail-open）；无人值守场景可改"恢复上次保护"（按持久化会话重建保护）；
  - 客户端丢失判定阈值（秒）；
  - 仅交流电源保持运行：电池供电时挂起电源保护请求，恢复交流后自动续上；
  - 手动保护最长时长（0 = 不限）；
  - 允许远程会话期间启用输入隔离（默认关闭，安全优先）；
  - 日志级别。

## 7. 日志与数据

- 主界面"日志"按钮查看最近 500 条操作日志（级别/时间/类别/消息）。
- 服务日志文件：`C:\ProgramData\Guardian\logs\guardian-YYYYMMDD.log`（开发模式：`%LOCALAPPDATA%\Guardian\logs`）。
- 数据库：`C:\ProgramData\Guardian\guardian.db`（SQLite；仅保存配置、会话记录、日志与能力报告，**不保存屏幕内容、键鼠内容或 AI 对话**）。

## 8. 异常情况对照

| 现象 | 含义与处置 |
|---|---|
| 状态显示"异常/未知" | 服务无法确认真实保护状态。优先点击"紧急恢复"，再检查服务状态。 |
| 服务未运行横幅 | 服务停止或被卸载。保护资源已由 fail-open 机制释放；点击横幅安装/启动服务。 |
| 输入隔离后鼠标键盘无响应 | 属预期行为。按 `Ctrl+Alt+Shift+F12` 紧急恢复；Ctrl+Alt+Del 也始终可用。 |
| 远程画面黑屏/花屏 | 先按紧急恢复恢复本地显示，再按 docs/技术兼容性报告.md 排查捕获兼容性并记录验证失败。 |
| 电池供电时"电源保护"显示已挂起 | 设置了"仅交流电"策略的正常表现，恢复交流电后自动续上。 |
| 串流环境显示"需要处理" | 环境处于中间态（典型：配置已改但服务未重启，或虚拟屏未被枚举命中）。展开"自检详情"看是哪一步，再点"一键恢复"。 |
| 串流环境提示"已拦停" | 虚拟屏没有被确认可用输出，Guardian 拒绝写入"只留虚拟屏"配置——继续会把本机变成没有画面的状态。按自检详情里的提示处理。 |

## 9. 串流环境（一键启用 / 一键恢复）

主窗口的"串流环境"卡片用于把本机准备成 **Sunshine 虚拟显示屏形态**（串流时只输出虚拟屏、本地物理屏熄灭），或退回 **物理屏形态**（物理屏亮、串流物理屏）。

- **一键启用**：按顺序执行 Sunshine 安装检查 → 虚拟显示驱动/设备 → 枚举确认 → 写入 Sunshine 配置 → 重启 Sunshine 服务。缺失的组件会自动下载安装（Sunshine 安装包约 33 MB，国内直连约 3 分钟，界面上会显示进度）。只要不点"一键恢复"，该形态一直保留。
- **一键恢复**：还原 Sunshine 配置 → 重启服务 → 把物理屏夺回主显 → 禁用虚拟设备。**不会卸载驱动**，下次一键启用秒级恢复。
- 卡片显示的是**探测到的事实**：Sunshine 版本、虚拟设备状态、配置文件形态、运行进程实际生效形态、物理屏是否活动。"配置与运行不一致"表示还差一次重启，此时环境属"需要处理"，不会替你美化成已就绪。
- 按钮只准备环境，**不会**同时开启保护或待机；黑屏仍由"开启保护""待机模式"负责。
- 无网络或下载过慢时：在设置里指定"离线目录"，把同名安装包放进去（卡片自检面板会显示官方地址与期望 SHA256，自行核对后拷入），一键启用会优先用本地文件。
- 特权动作全部由 GuardianService 以 SYSTEM 静默完成，**不会弹 UAC**；前提是服务已安装并运行（未安装时先点顶部横幅安装服务）。

### 全新机器上的唯一一次手工步骤

虚拟屏幕的"造出监视器"这一步不由驱动自动完成（实测：驱动入库、根设备创建、设备启用、甚至重启设备都做完，等 30 秒仍然没有监视器对象）。因此**第一次**在新机器上用这个功能时：

1. 点"一键启用"，卡片会拦停并写明"需要用厂商工具 VDD Control 点一次 Add display"
2. 打开厂商工具（验证包 `4-厂商工具` 目录内），只点 **Add display**，**不要重装驱动**
3. 回到 Guardian 再点一次"一键启用" —— 之后全部自动，重启电脑也保持

这一步之后不需要再做第二次。
- 输入不保存：该功能只读写 Sunshine 配置文件与设备状态，不读取屏幕内容、不读取 Sunshine 的 `credentials` 目录。

## 10. 硬件前提与已知限制

- 该功能依赖第三方 Virtual Display Driver。**在"独显直连"（只有 dGPU 被枚举、核显关闭）的笔记本上，目前公开发布的签名驱动无法创建可用虚拟输出**：驱动会创建监视器又立刻拆掉（其日志里是 `Failed to set device to swap chain`）。这种情况下 Guardian 的一键启用会停在自检的"虚拟屏枚举命中"一步，**物理屏不受任何影响**，一键恢复始终可用。
- 全新机器第一次使用时，需要在厂商工具里以管理员身份运行并执行一次 `SETCOUNT 1` + Restart Driver；Guardian 也会自动放置驱动所需的 `vdd_settings.xml`（只在缺失时写入，不覆盖你改过的配置）。
- 安装器会注册开机自启（`Guardian.App --minimized`）。这是安全前提：紧急恢复热键与显示隐私只能在你的登录会话里生效，客户端不在场时这两项都不存在。卸载会一并清除该项。

## 11. 重启之后什么会保持

| 项目 | 重启后 | 说明 |
|---|---|---|
| 串流环境（一键启用后的接管形态） | **保持** | Sunshine 配置、虚拟设备启用状态、服务自启都是持久化的。开机后虚拟监视器由驱动重建，若驱动慢一步，卡片会如实显示"需要处理"，再点一次"一键启用"即可。 |
| 待机模式（开关） | **保持为"已启用"** | 武装状态持久化，开机自动恢复；但**不会**在开机时自动进入待机（屏幕保持点亮、不持有离开模式）。要立即进入待机请自己勾选。 |
| 保护状态、工作会话 | 按设置的"恢复策略"处理 | 见第 6 节设置。 |

待机模式保持启用时可以直接关机：离开模式请求随服务停止释放，不会挡住关机。若想彻底恢复正常睡眠行为，请取消勾选"启用待机模式"。
